 # Mount Baba-Bounce

 You are trying to climb a large mountain to reach your old ANGRY Russian Grandma.

 In order to do so you have to dash to the end of the mountain using shift,
 refill your dash stamina by jumping off walls with space,
 double jump by using space, A and D to move, and use SHIFT to dash in the direction you look.

 try to go as fast as you can.
